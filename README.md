# Граф зависимостей пакетов Ubuntu

Консольная программа для анализа зависимостей заданной версии пакета.

## Запуск

Нужен Python 3.10 или новее. Настройки читаются из JSON:

```sh
make run CONFIG=examples/demo.json
make test
```

В Windows можно выполнить:

```bat
set PYTHONPATH=src
python -m apt_graph --config examples/demo.json
python -m unittest discover -s tests -v
```

## Настройки

| Поле | Значение |
| --- | --- |
| `package` | Имя анализируемого пакета |
| `source` | URL индекса Packages или путь к тестовому репозиторию |
| `test_mode` | `true` для локального тестового репозитория |
| `version` | Точная версия корневого пакета |
| `output` | Имя выходного SVG |
| `max_depth` | Максимальная глубина; корень имеет глубину 0 |

Пути в конфигурации задаются относительно самого JSON-файла.

На первом этапе программа проверяет настройки и выводит их значения.
Ошибки выводятся в stderr, код завершения при ошибке равен 1.
